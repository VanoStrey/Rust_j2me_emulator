## 1. Лицензионный статус программного обеспечения

### 1.1. Собственный исходный код
- **Rust J2ME Emulator:** Исходный код крейтов (`j2me-core`, `j2me-stdlib`, `j2me-wasm`, `j2me-cli`) распространяется под разрешительными лицензиями (MIT / Apache-2.0).
- **J2ME Market UI & Server:** Веб-интерфейс, Three.js 3D-сцены и серверный код `server_rust` лицензированы под лицензией MIT (`j2me_market/LICENSE`).

### 1.2. Сторонние зависимости и границы Copyleft (GNU GPL v2)
- **FreeJ2ME:**
  - Исходный код ядра FreeJ2ME лицензирован под лицензией **GNU General Public License v2 (GPLv2)**.
  - В проекте Market расширение `org.recompile.freej2me.WebBridgeRunner.java` выполнено в полном соответствии с требованиями секции 2(b) GPLv2: исходный код адаптера открыт в репозитории (`tools/freej2me/`), текст `LICENSE-GPL2.txt` присутствует в корне проекта.
  - Серверный код Rust взаимодействует с FreeJ2ME исключительно через внешний процесс (`Command::new("java")`) и сетевой сокет HTTP/TCP, что не создает производного произведения по определению Free Software Foundation.
- **Three.js, miniz_oxide, serde, tiny_http:**
  - Все сторонние библиотеки используют разрешительные лицензии MIT, Apache-2.0 или BSD-2-Clause, не налагающие ограничений на дистрибуцию.

## 2. Анализ критических рисков: Коммерческие игровые ROM-файлы

### 2.1. Конфликт между документацией и продакшн-деплоем
В документе `j2me_market/docs/CONTENT_LICENSE_AUDIT.md` (секция 4 и 5) официально зафиксировано:
> *«Все 16 коммерческих JAR-файлов находятся под защитой авторского права соответствующих правообладателей... Включение данных бинарных файлов в публичный релизный пакет дистрибутива недопустимо. Скрипт сборки дистрибутива в обязательном порядке исключает директорию `roms/raw/*.jar`. Применяется модель Bring Your Own ROMs (BYOR)».*

**Фактическое состояние боевого сервера (PROVEN CONFLICT):**
1. В скрипте развертывания `scripts/deploy_to_server.py`:
   ```python
   def sync_roms():
       print("🎮 Step 5: Syncing ROMs archive (3.2 GB)...")
       run_cmd(f"rsync -avz {LOCAL_DIR}/roms/ {SERVER_ALIAS}:{REMOTE_DIR}/roms/")
   ```
2. В конфигурации Nginx на боевом сервере `177.3.222.50`:
   ```nginx
   location /roms/ {
       alias /opt/j2me_market/roms/;
       types {
           application/java-archive jar;
           text/vnd.sun.j2me.app-descriptor jad;
       }
       expires 30d;
   }
   ```
3. В маршрутизаторе `server_rust/src/router.rs`:
   - Путь `/roms/` открыт для прямого скачивания любых файлов.
   - Эндпоинт `/api/archive/download?slug=...` напрямую отдает файлы коммерческих игр из архива.

### 2.2. Юридические последствия и правовые риски
- Прямая раздача бинарных исполняемых пакетов игр, принадлежащих компаниям Gameloft SE, Konami Digital Entertainment, id Software, Sony Interactive Entertainment, Capcom и Rovio Entertainment, представляет собой прямое нарушение исключительных авторских прав в юрисдикциях РФ (ст. 1270 ГК РФ), ЕС (EU Copyright Directive) и США (DMCA Title 17 U.S. Code).
- Публичный хостинг на IP-адресе `177.3.222.50` создает прямую угрозу получения абуз (DMCA Takedown Notices), блокировки хостинг-провайдера и юридического преследования оператора проекта.

## 3. Практический план приведения к соответствию (Compliance Action Plan)

1. **Немедленно (День 1):**
   - Закрыть прямой публичный доступ к локейшену `/roms/` в Nginx (директива `internal;` либо удаление публичного маппинга).
2. **Внедрение чистой BYOR-архитектуры:**
   - Предоставить в интерфейсе кнопку «Загрузить свой JAR» (Drag & Drop Sideloading). Пользователь выбирает локальный JAR-файл с диска, и браузерный WASM-эмулятор моментально запускает его без отправки на сервер.
   - Для демонстрации возможностей эмулятора в публичном каталоге использовать свободные Homebrew-игры и демосцену под лицензиями Creative Commons / Open Source (например, игры с соревнований J2ME Retro Jams).
3. **Сохранение архива исключительно в исследовательских целях:**
   - Если сервер позиционируется как закрытый некоммерческий исследовательский архив, доступ к ROM должен быть ограничен авторизацией исследователей с дисклеймером о добросовестном использовании (Fair Use / Preservation).
